    SYSTEM SEQUENCE

    How it works

    Field conditions flow through eligibility, capacity, and priority allocation to multiple valve outputs.

    01FIELD
    CONDITIONS
    →
    02BOOLEAN
    LOGIC
    →
    03IRRIGATION
    REQUEST
    →
    04PRIORITY
    LOGIC
    →
    05VALVE
    OUTPUT
    1. Each zone provides digital input conditions.
    2. Boolean logic determines whether irrigation is required.
    3. Water availability is checked.
    4. Eligible zones are identified.
    5. Water capacity activates all eligible zones when possible; priority is used only when demand exceeds it.
    6. Each allocated valve is activated.

    PROJECT INTENT

    The idea

    Traditional irrigation may water areas that do not need it. This controller isolates the decision layer and allocates water with deterministic digital logic. D = Soil Dry, R = Rain Detected, W = Water Available.
